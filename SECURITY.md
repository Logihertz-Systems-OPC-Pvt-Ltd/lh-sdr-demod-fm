## Reporting a Vulnerability

Logihertz Systems (OPC) Private Limited maintains high assurance standards for software-defined radio (SDR) and digital signal processing (DSP) pipelines. If you discover a vulnerability or potential buffer overflow, integer overflow, or denial-of-service vector in `lh-sdr-demod-fm`, please report it through coordinated disclosure.

### Reporting Channels

- **Primary Contact**: Sameer Tawade (Creator, Founder, Director & Sole Developer)
- **Email**: [`security@logihertz.com`](mailto:security@logihertz.com)
- **Alternate**: [`ops@logihertz.com`](mailto:ops@logihertz.com)

### Details to Provide

1. Product name (`lh-sdr-demod-fm`) and release version (`0.1.0`).
2. Vector classification (e.g. malformed IQ input crash, WAV header buffer overflow, JSON parser memory leak, or SIMD alignment fault).
3. Reproduction artifacts (sample IQ file or receiver config JSON manifest).
4. Expected vs observed behavior.

### Response SLA

- **Initial Triage**: Within 24-48 hours.
- **Remediation & Patch**: Within 14 business days.
- **Public Advisory**: Published concurrently with the patch release.
